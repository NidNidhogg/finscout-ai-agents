# Data

Canonical reference datasets and fixture corpus for FinScout modules.

## Structure

- `data/*.json` — canonical reference data that modules load at runtime (e.g., `icp-reference.json`, `fingerprint.json`). Hand-authored or generated by committed scripts. Always committed.
- `data/fixtures/` — test corpus used by module test suites. Schema must match Zod types defined in `/src/schema/`.
  - `data/fixtures/pages/` — captured website-crawl outputs per company. Used as input to Stage 2 (Website Qualifier) tests.
  - `data/fixtures/tweets/` — captured tweet samples. Used as input to Stage 1 (X Funding-Listener) tests.

## Commit policy

- Canonical JSON at the top level is always committed.
- Fixture corpus is committed if under 10MB total per subdirectory; otherwise gitignored and regenerable via scripts under `/scripts/`.
- Never commit secrets, API keys, or personally identifiable information from any source.
